README

Welcome to The Art Studio, an exquisitely designed website featuring some beautiful home decor and furniture pieces.

Overview of the Website

The Art Studio is a responsive website built with HTML, CSS, and JavaScript that features a fully functional navigation bar, product pages, and e-commerce functionality.

Pages

- Home: The visually appealing landing page that shows beautiful image gallery and featured products.
- Decor: A description page that displays a curated selection of home decor essentials.
- Kitchen Decor/Bath Decor/Wall Decor/Furniture: Products with price tags and "Add to Cart" buttons.
- About Us: A page sharing our story, mission, and values.
- Contact Us : A page with contact information.
- Log In: A secure login page for registered users.
- Registration: For the registration of new users.

Features:

- Fully functional navigation bar with a dropdown menu for desktop and big screens.
- Hamburger menu for small screens.
- Product pages with price tags, descriptions, and "Add to Cart" buttons.
- E-commerce functionality with cart management.
- Secure login and registration pages.

Technical Details:

-Built with HTML5, CSS, and JavaScript. 
- Used JavaScript library: jQuery.
-Responsive design that allows for an optimal view from most devices.
